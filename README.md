# Dig-To-Hell

Browser idle/clicker: dig a mine shaft, hire crew, find absurd things. See `claude.md` and `Spec.md`.

```
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build to dist/
```

Tuning numbers live in `src/config.ts`. `dig-to-hell.html` is the original single-file prototype (reference only).
